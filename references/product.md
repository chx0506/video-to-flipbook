# 火种产品契约（Skill 视角）

> 完整产品逻辑见仓库 `huozhong/PRODUCT.md`（SSOT）。本文只摘 Skill 必须对齐的部分。

## 一句话

**我看到，我做到。** —— 把别人的经验，变成**自己的下一步**。

## 本 Skill 在产品里的位置

```
┌──────────────────────────────────────────────────────────┐
│              火种 = 看视频 → 理解 → 行动 的完整方案         │
├────────────────────────────┬─────────────────────────────┤
│  A · 单视频层（弹幕陪看）    │  B · 多源综合层（本 Skill）   │
│  信息流里持续发生            │  片段 → 一个交互网页应用       │
└────────────────────────────┴─────────────────────────────┘
```

**本 Skill 负责 B 层（及 A 层「成页」形态）：** 把视频 / 灵感片段分析成 **一个可交互网页应用**（flipbook），
用户在页内完成个性化决策后，再编译 **行动清单**（存 App / 打印小票）。

不负责：弹幕、灵感库 UI、Feed 刷法、实践后反馈社区 —— 宿主 App 提供入口与壳。

## 两条入口，同一条输出

| 入口 | 用户状态 | Skill 收到的典型输入 |
|------|----------|----------------------|
| **刷到被启发** | 被种草，想进一步决策 | Mode A 单片段，或攒够后 Mode B 多片段 |
| **带着问题来** | 现实问题，要交叉验证 | Mode B + 明确的 `meta.task` |

两条路最终都是：**多源信息 → 一个交互网页 → 个性化点选 → 行动清单**。

## 正确操作路径（Skill 应对齐）

```
视频 / 灵感片段（含起止时间、整条保留、其余 TLDR）
    → analyze → data_<name>.json
    → 交互网页（overview + cards + 品类交互 widget）
    → 用户点选个性化
    → 编译行动清单（运行时，非 JSON 写死）
    → postMessage / 打印 → 宿主 App 行动库
```

## 交互网页 = 新内容形态

每个 `out_<name>.html` 必须：

1. **背后有一个非常具体的场景和问题** —— 写在 `meta.task`（多源）或 `meta.subtitle`（单源）
2. **网页本身完成「理解 + 决策」** —— 图解、点选、计算器、对比，不是文章摘要
3. **清单是交互结果的编译物** —— 见 `action-list.md`；禁止页头预置成品待办

## 行动清单短链（不可打断）

```
视频 → 网页（完整交互设计）
    → 用户点选
    → 个性化方案（攻略 / 采购 / 训练计划…）
    → 行动清单
    → 存 App / 打印小票
    → 现实打勾
```

- 改选择 → 清单条目跟着变
- 不同品类 → 不同清单形态（见 `content-categories.md`）
- 同类不同画像 → 清单也不同（亲子游 ≠ 打卡游）

## 产品反模式（Skill 输出禁止）

| 反模式 | 正确做法 |
|--------|----------|
| 搜索式丢回一堆视频摘要 | 输出 **一个** 任务形交互应用 |
| 一进页就有写死行李/采购清单 | `meta.actionList` 只写品类提示；items 由交互编译 |
| 生成综合页时 JSON 预塞 `items[]` | `compileFrom: "user-selection"` |
| 只有「再看一遍视频」类伪行动 | 清单条目必须可在线下执行（买、装、练、订） |
| 多源只是 N 段摘要拼接 | 去重 + 共识/冲突/互补，结构因多源而改变 |

## 与宿主 App 的接口

| 能力 | 机制 |
|------|------|
| 内嵌展示 | `?embed=1` / iframe → `body.embed` |
| 存入行动库 | `postMessage` → `{ type: "huozhong:action-list", action: "save", payload }` |
| 打印小票 | 同上 `action: "print"`；浏览器 `@media print` 热敏窄条样式 |
| 灵感库多选输入 | Mode B `clips[]` → `meta.sources[]`（见 `multi-video.md`） |
